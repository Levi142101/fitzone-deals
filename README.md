# FitZone Deals

Best fitness & health deals on Amazon — updated daily.

🔗 **Live site:** [fitzone-deals.netlify.app](https://fitzone-deals.netlify.app)

## Features
- 50+ real Amazon products with verified price drops
- 90-day price history charts
- Links to CamelCamelCamel & Keepa for full tracking
- 9 categories: Wearables, Equipment, Supplements, Recovery, Yoga, Nutrition, Apparel, Cardio
- Mobile responsive design
- Amazon Associates affiliate integration

## Tech

- Vanilla CSS
- Hosted on Netlify (auto-deploy from this repo)
